# 开发计划：豆包组图生成

## Context

用户已完成主Agent委派架构和单图生成测试，接下来需要开发豆包**组图生成**功能。组图指一次生成多张连贯/连续的插画（Sequential Image Generation）。

用户明确指示：
1. 使用 DoubaoClient 已有的流式组图方法 `generate_images_stream`
2. `generate_images_stream` 支持 `response_format="url"` 参数，需要将其从硬编码的 `b64_json` 改为可配置

## 目标

修改 `generate_images_stream` 使其支持 `response_format="url"`，在异步环境中正确收集流式 URL 结果。

## 实施方案

### 步骤1：修改 client.py 中的 generate_images_stream

**文件：** `backend/huesaeagents/huesae/tools/doubao/client.py`

给 `generate_images_stream` 添加 `response_format: str = "url"` 参数，替代硬编码的 `"b64_json"`：
- 参数签名新增 `response_format: str = "url"`
- `self.client.images.generate` 调用中使用该参数
- 事件处理逻辑根据 `response_format` 决定 yield `event.b64_json` 还是 `event.url`
- 当 `event.type == "image_generation.partial_succeeded"` 时：
  - `response_format == "url"` → yield `event.url`
  - 否则 → yield `event.b64_json`

### 步骤2：修复 image.py 中的组图封装

**文件：** `backend/huesaeagents/huesae/tools/image.py`

当前 `generate_images_by_doubao` 函数（line 184-225）调用了不存在的 `doubao_generate_images`。需要：
- 改为调用 `DoubaoClient.generate_images_stream`
- 传入 `response_format="url"`
- 使用 `asyncio.to_thread` 在后台线程执行同步 Generator 并收集结果
- 返回 `list[str]`（URL 列表）

### 步骤3：在 agent_tools.py 添加组图工具

**文件：** `backend/huesaeagents/huesae/agents/utils/agent_tools.py`

新增 `generate_images_doubao` 工具函数：
- 调用 `generate_images_by_doubao`
- 返回 `list[str]`（URL 列表）
- 添加到 `IMAGE_TOOLS` 列表中

## 验证方案

1. `client.py`：`generate_images_stream` 支持 `response_format="url"` 参数
2. `image.py`：`generate_images_by_doubao` 返回 `list[str]`（URL 列表）
3. `agent_tools.py`：`IMAGE_TOOLS` 包含新工具 `generate_images_doubao`
