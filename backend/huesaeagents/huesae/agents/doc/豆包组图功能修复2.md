# 开发计划：组图能力集成到 Image Agent

## Context

豆包组图生成的基础能力已就绪。用户明确：`max_images` 是**最大限制**（上限），不需要从用户输入中提取传给豆包——豆包内部会从 prompt 中识别数量（如"生成4张"→实际生成4张）。我们需要做的只是：判断何时该调用组图 API，然后给 `max_images` 设一个足够大的上限即可。

## 目标

实现用户示例中的完整组图对话流：
1. 用户说"生成4张图片" → LLM 识别为组图模式 → 调用组图 API（max_images 设上限如12）
2. 扩写/推荐/确认过程中保留组图意图（prompt 中自然包含数量信息）
3. "换一组"时保留组图意图（从对话历史/current_image_prompt 中识别）
4. 生成后展示多张图片 URL

**约束：尽量减少对单图功能的修改，单图路径已测试成功。**

## 关键设计决策

- **组图判断**：由 `ImageDecision` 新增 `is_batch: bool` 字段，LLM 根据用户输入中的组图关键词（"几张""一组""系列""4张"等）判断
- **max_images 为固定上限**：组图调用时固定传入 `max_images=12`（或从配置读取），不作为状态传递
- **不新增状态字段**：`current_image_prompt` 已包含数量描述，LLM 可从对话历史重新判断组图意图
- **单图路径完全不变**：`is_batch=false` 时走原有 `generate_image()` → `image_url` 路径

## 实施方案

### 步骤1：Prompt 层修改

**文件：** `backend/huesaeagents/huesae/agents/subagents/image/prompts.py`

修改 `IMAGE_CONVERSATION_PROMPT`：
- JSON 输出添加 `is_batch: bool` 字段说明：
  - 用户**明确说明**生成数量（如"生成4张""给我3张图"）→ `is_batch=true`
  - 用户不提数量，或明确说"生成1张图""一张" → `is_batch=false`（默认单图）
- "执行生图"步骤添加：`is_batch=true` 时使用组图功能（豆包会自动根据 prompt 决定实际张数）
- "图片展示后处理"中：用户说"换一张""重新生成"时，根据历史 prompt 判断是否组图

### 步骤2：ImageSubAgent 修改

**文件：** `backend/huesaeagents/huesae/agents/subagents/image_agent.py`

1. `ImageDecision` 添加 `is_batch: bool = Field(default=False, description="是否使用组图模式，用户要求多张图片时为true")`
2. `_handle_generate()` 返回结果中加入 `is_batch=decision.is_batch`
3. 新增 `generate_images()` 方法：
   - 参数：`prompt`, `provider_name`, `size`, `output_format`
   - 内部调用 `client.generate_images_stream(prompt, max_images=12, ...)` 收集 URL
   - `max_images` 固定为 12（上限，豆包内部根据 prompt 决定实际张数）
   - 返回 `list[GenerationResult]`

### 步骤3：主Agent修改

**文件：** `backend/huesaeagents/huesae/agents/lead_agent/lead_agent.py`

1. `_handle_sub_agent()` — action="generate" 时：
   - 读取 `is_batch = sub_result.get("is_batch", False)`
   - 返回结果中加入 `"is_batch": is_batch`
2. `execute_image_generation()` — 添加 `is_batch: bool = False` 参数：
   - `is_batch=true`：调用 `agent.generate_images()`，返回 `{"wrap_message", "image_urls": [...]}`
   - `is_batch=false`：保持原有 `agent.generate_image()`，返回 `{"wrap_message", "image_url"}`

### 步骤4：交互层修改

**文件：** `backend/huesaeagents/huesae/agents/lead_agent/chat_loop.py`

1. `pending_generation` 处理：
   - 从 result 读取 `is_batch`
   - 调用 `execute_image_generation(..., is_batch=is_batch)`
   - 判断返回结果：
     - 有 `image_urls` → 循环打印 `[图片] {url}` 每张一行
     - 有 `image_url` → 保持原有单图打印

## 不修改的文件

- `huesae_state.py` — 不新增字段（数量信息已包含在 prompt 中）
- `state_manager.py` — 不新增序列化字段

## 验证方案

运行终端交互 `python backend/huesaeagents/huesae/agents/lead_agent/chat_loop.py`：

1. 用户："生成4张四季插画" → 子Agent识别 `is_batch=true` → 确认后调用组图 → 输出多个 URL
2. 用户："换一组" → 从历史 prompt 识别组图 → 重新生成多张
3. 用户："生成1张夕阳下的大海" → 走单图路径 → 输出1个 URL（单图功能无回归）
