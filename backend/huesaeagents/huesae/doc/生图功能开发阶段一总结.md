# HuesaeAgents - 生图功能开发阶段一总结

**开发日期**: 2026-05-10  
**目标**: 搭建小生图Agent，支持三种模式：直接生图 / 转Danbooru标签 / 扩写提示词  
**虚拟环境**: `conda activate HuesaeAgents`

---

## 一、阶段目标

基于已有工具（即梦/豆包生图），搭建一个可独立运行的小生图Agent，支持三种交互模式：

| 模式 | 触发条件 | 流程 |
|------|---------|------|
| **A. 直接生图** | 用户说"画一个..." | 检查提示词长度→选择工具(豆包/即梦)→生图→换图/结束 |
| **B. 转Danbooru标签** | 用户说"转成Danbooru标签" | 生成Danbooru标签→换版本/结束（不生图） |
| **C. 扩写提示词** | 用户说"扩写提示词" | 扩写自然语言→接受/拒绝 |

## 三、代码架构

### 3.1 类图

```
ImageAgent (独立类)
    ├── llm: BaseChatModel
    ├── providers: dict[str, ImageProvider]
    │       ├── DoubaoProvider ──→ huesae.tools.image.generate_image_by_doubao
    │       └── JimengProvider ──→ huesae.tools.image.generate_image_by_jimeng
    │
    ├── _detect_mode(user_input) → ImageMode
    ├── process_input(user_input) → {mode, step, prompt, message}
    ├── process_step(state, user_input) → {step, message}
    ├── generate_image(prompt, provider) → GenerationResult
    │
    ├── _handle_direct_image_input(prompt) → 直接生图流程
    ├── _handle_convert_tags_input(prompt) → 转Danbooru标签流程
    └── _handle_expand_prompt_input(prompt) → 扩写提示词流程

danbooru.py
    └── generate_tags(user_input, llm) → list[str]

expand_prompt.py
    └── expand_prompt(user_input, llm) → str
```

### 3.2 开闭原则实现

| 扩展点 | 方式 | 示例 |
|--------|------|------|
| 新增Provider | 继承`ImageProvider`，调用`register_provider()` | `ComfyUIProvider` |
| 修改默认Provider | 构造函数参数 | `ImageAgent(default_provider="jimeng")` |
| 新增模式 | 添加`ImageMode`常量 + 对应处理方法 | `STYLE_TRANSFER`模式 |

## 四、三种模式流程

### 模式A：直接生图

```
用户: "画一个银发红瞳的少女在樱花树下"
    │
    ▼
ImageAgent._detect_mode() → ImageMode.DIRECT_IMAGE
    │
    ▼
ImageAgent._handle_direct_image_input()
    │ 检查提示词长度（≥5字）
    ▼
AI: "想要生成图片：一个银发红瞳的少女在樱花树下
    请选择生图工具：doubao / jimeng
    （输入工具名即可）"
    │
用户: "doubao"
    │
    ▼
ImageAgent._handle_select_tool()
    │ → selected_provider = "doubao"
    ▼
[调用 DoubaoProvider.generate(prompt)]
    ▼
AI: "图片生成完成！
    工具：doubao
    提示词：一个银发红瞳的少女在樱花树下
    {url}
    是否换一张？（换一张 / 可以）"
    │
用户: "换一张"
    │
    ▼
[用doubao重新生成相同提示词]
    ▼
AI: "重新生成完成！{url} 是否换一张？（换一张 / 可以）"
    │
用户: "可以"
    │
    ▼
AI: "图片生成完成！如果还想画别的，随时告诉我~"
```

### 模式B：转Danbooru标签

```
用户: "转成Danbooru标签：一个银发红瞳的少女"
    │
    ▼
ImageAgent._detect_mode() → ImageMode.CONVERT_TAGS
    │
    ▼
ImageAgent._handle_convert_tags_input()
    │ LLM生成标签
    │ → ["1girl", "silver_hair", "red_eyes", ...]
    ▼
AI: "为你生成的Danbooru标签：
    1girl, silver_hair, red_eyes, ...
    是否满意？（可以了 / 换一版）"
    │
用户: "换一版"
    │
    ▼
[重新生成标签]
    ▼
AI: "重新生成的Danbooru标签：...
    是否满意？（可以了 / 换一版）"
    │
用户: "可以了"
    │
    ▼
AI: "标签生成完成！需要生图的话告诉我~"
```

### 模式C：扩写提示词

```
用户: "扩写提示词：一个银发红瞳的少女"
    │
    ▼
ImageAgent._detect_mode() → ImageMode.EXPAND_PROMPT
    │
    ▼
ImageAgent._handle_expand_prompt_input()
    │ LLM扩写
    ▼
AI: "扩写后的描述：
    一位银发如瀑布般倾泻的少女，红宝石般的眼眸...
    是否接受这版？（接受 / 再写一版）"
    │
用户: "接受"
    │
    ▼
AI: "扩写完成！需要生图或转Danbooru标签的话告诉我~"
```

### 短提示词处理

```
用户: "画个猫"
    │
    ▼
AI: "提示词太短啦，请告诉我更详细的描述（至少5个字）~

    │
用户: "画一只橘色的猫在窗台上睡觉"
    │
    ▼
[继续正常流程]
```

## 五、LangGraph 接入

`graph/huesae_graph.py` 已将 `image_agent_node` 接入主工作流，支持多轮交互：

```python
workflow = StateGraph(HuesaeState)
workflow.add_node("image_agent", image_agent_node)
workflow.add_conditional_edges("classify_intent", route_by_intent, {
    "image_agent": "image_agent",
    ...
})
```

状态字段：
- `image_mode`: 当前模式（direct_image / convert_tags / expand_prompt）
- `image_step`: 当前步骤（input / select_tool / generate_image / show_image / ...）
- `image_prompt`: 当前提示词
- `need_more_input`: 是否需要补充输入
