# 架构重构：LangChain + 主智能体委派

## Context

当前 LangGraph 多节点路由架构导致了三个体验问题：
1. **URL 重复打印**：`image_step="show_image"` 状态下用户说"真好看"，子图Agent返回 `finish` 但 `generated_image_url` 仍残留在 state 中，`run_chat_loop` 再次打印 `[图片]`
2. **割裂感**：子图Agent返回 `finish` 后终端打印 `[生图对话已结束]`，下一轮才进入主Agent，对话流断裂
3. **状态锁定粗暴**：`classify_intent` 用 `image_step != "finish"` 硬编码锁定路由，导致无关输入也被迫走生图Agent

根本原因：**LangGraph 的节点路由被 `image_step` 状态劫持，主Agent失去了对对话流的自然掌控**。

用户选择的重构方向：LangChain + 主智能体委派机制。主Agent始终是对话核心，子Agent作为可调用组件。

## 设计方案

### 一、整体架构

```
┌─────────────────────────────────────────────┐
│           HuesaeMainAgent（主Agent）          │
│  - 角色语气、情绪状态                          │
│  - 每轮用 LLM 做意图分类                       │
│  - 调用子Agent 或 直接聊天回复                 │
│  - 包装子Agent结果，自然过渡                   │
└──────────────┬──────────────────────────────┘
               │
    ┌──────────┴──────────┐
    │                     │
┌───▼────────┐      ┌─────▼──────┐
│ ImageAgent │      │ SearchAgent│  （未来扩展）
│ - 生图     │      │ - 搜索     │
│ - 扩写     │      │            │
│ - 标签     │      │            │
└────────────┘      └────────────┘
```

### 二、主Agent 职责

**文件：** `backend/huesaeagents/huesae/agents/main_agent.py`（新建）

```python
class HuesaeMainAgent:
    """主Agent：对话核心 + 子Agent委派"""

    def __init__(self, llm, character_id="gentle_sister"):
        self.llm = llm
        self.character_id = character_id
        self.sub_agents = {}  # 子Agent注册表

    def register_sub_agent(self, name: str, agent: BaseSubAgent):
        self.sub_agents[name] = agent

    def process(self, state: dict, user_input: str) -> dict:
        # 1. 意图分类
        intent = self._classify_intent(state, user_input)

        # 2. 如果意图匹配子Agent，调用子Agent
        if intent in self.sub_agents:
            sub_result = self.sub_agents[intent].process(state, user_input)

            # 子Agent返回的是"生图流程中的一步"（追问/推荐/确认）
            if sub_result["action"] in ("ask_prompt", "recommend", "ask_confirm"):
                return {"messages": [AIMessage(content=sub_result["response"])]}

            # 子Agent返回的是"执行生图"
            if sub_result["action"] == "generate":
                # 主Agent调用生图，然后包装展示
                image_url = self._generate_image(sub_result["prompt"])
                wrap_msg = self._create_wrap_message(image_url)
                return {
                    "messages": [
                        AIMessage(content=sub_result["response"]),  # "图片正在生成中~"
                        AIMessage(content=wrap_msg),  # "这是生成好的图片哦~"
                    ],
                    "image_url": image_url,
                }

            # 子Agent返回结束
            if sub_result["action"] == "finish":
                # 主Agent用角色语气回复结束语
                return {"messages": [AIMessage(content=self._chat_reply(state, user_input))]}

        # 3. 否则主Agent直接聊天回复
        return {"messages": [AIMessage(content=self._chat_reply(state, user_input))]}
```

**关键改变**：
- 意图分类时把**完整对话历史**传给 LLM，让 LLM 自己判断"用户是在继续生图对话还是切回聊天"
- 不再需要 `image_step` 状态字段做硬编码路由
- 生图完成后主Agent直接包装展示，没有中间状态

### 三、子Agent 接口标准化

**文件：** `backend/huesaeagents/huesae/agents/subagents/base.py`（新建）

```python
class BaseSubAgent(ABC):
    """子Agent基类"""

    @abstractmethod
    def process(self, state: dict, user_input: str) -> dict:
        """处理用户输入，返回标准化结果

        Returns:
            {
                "action": "ask_prompt|recommend|expand|ask_confirm|generate|finish",
                "response": "给用户的回复（供主Agent包装或直接展示）",
                "prompt": "确认的提示词（generate时）",
                "data": {}  # 额外数据
            }
        """
        pass
```

**文件：** `backend/huesaeagents/huesae/agents/subagents/image_agent.py`（改造）

改造现有 `ImageConversationManager`：
1. 继承 `BaseSubAgent`
2. `process()` 返回标准化格式，不再直接构造 `AIMessage`
3. 内部 `_decide()` 逻辑保持不变（LLM 分析对话历史做决策）
4. 删除与 LangGraph 状态耦合的代码（`image_step` 等字段的读写）

### 四、终端交互层

**文件：** `backend/huesaeagents/huesae/graph/huesae_graph.py`（简化）

简化 `run_chat_loop()`：
- 不再需要 `graph.invoke()` 和 checkpoint
- 直接用 `HuesaeMainAgent` 实例处理每轮输入
- 维护一个 `messages` 列表作为对话历史
- 图片 URL 只在主Agent返回的 `image_url` 存在时打印一次

```python
def run_chat_loop():
    agent = create_main_agent()
    messages = []

    while True:
        user_input = input("用户: ").strip()
        result = agent.process({"messages": messages}, user_input)

        for msg in result["messages"]:
            print(f"AI: {msg.content}\n")

        if result.get("image_url"):
            print(f"[图片] {result['image_url']}\n")

        messages.extend([HumanMessage(content=user_input), *result["messages"]])
```

### 六、验证方案

运行终端交互：
```bash
python backend/huesaeagents/huesae/graph/huesae_graph.py
```

验证对话流：
1. 用户："今天天气如何" → 主Agent直接聊天回复
2. 用户："我想生成图片" → 主Agent分类为 image → 调用 ImageAgent → 追问"请描述一下~"
3. 用户："夕阳下看大海的少女" → ImageAgent 决策 generate → 主Agent生图 + 包装展示
4. 用户："真好看" → 主Agent分类为 chat → 直接回复"呜~太好了！您喜欢这张图..."（无 URL 重复、无割裂提示）
5. 用户："谢谢" → 主Agent正常聊天回复
