# 重构意图识别与子图Agent：LLM驱动对话管理

## Context

当前架构的两个核心问题：

1. **主图意图识别用关键词匹配**（`conditional_logic.py` 的 `classify_intent`），需要改为LLM原生识别
2. **子图Agent用硬编码状态机**（`image_agent.py` 的 `ImageStep` 分支），无法支持灵活的"追问-推荐-扩写-确认"对话流

用户要求实现"思考-澄清-行动"闭环，三个核心例子：
- 用户说"我想生成图片"→子图追问提示词→用户提供→生图
- 用户要推荐→子图主动推荐→用户修改→生图
- 推荐后用户说太短→追问→扩写→确认→生图

## 设计方案

### 一、主图：LLM粗分类意图

**文件：** `backend/huesaeagents/huesae/graph/conditional_logic.py`

`classify_intent` 改为LLM识别，但只做**粗分类**（chat/image/voice/memory/search/remind/safe），不细分生图的具体模式。

关键规则：**如果已经在子图对话中（`image_step` 存在且不是 finish），直接返回 IMAGE**，避免用户回复"夕阳下看大海的少女"时被误判为 chat。

```python
def classify_intent(state: HuesaeState) -> str:
    # 1. 如果已在生图对话中，保持IMAGE意图
    if state.get("image_step") and state.get("image_step") != "finish":
        return Intent.IMAGE
    
    # 2. 用LLM做粗分类
    # 输入：用户最新消息
    # 输出：Intent（chat/image/voice/memory/search/remind/safe）
```

### 二、子图：LLM驱动的对话管理器

**核心思想**：用一个LLM决策模型替代硬编码状态机。每个回合，LLM分析完整对话历史，输出"下一步动作"。

**文件：** `backend/huesaeagents/huesae/agents/subagents/image_agent.py`（重写）

#### 2.1 决策模型

```python
class ImageDecision(BaseModel):
    """子图Agent每回合的决策"""
    thought: str = Field(description="分析当前对话状态和用户需求")
    action: Literal[
        "ask_prompt",       # 追问：缺少提示词，请用户描述
        "recommend",        # 推荐：主动生成推荐提示词供选择
        "expand",           # 扩写：将简短描述扩写为详细提示词
        "ask_confirm",      # 确认：推荐/扩写后询问用户是否满意
        "generate",         # 生图：调用provider生成图片
        "show_image",       # 展示：图片已生成，展示并询问是否换图
        "finish",           # 结束：对话完成
    ] = Field(description="下一步动作")
    response: str = Field(description="给用户的回复消息，用温柔二次元语气")
    prompt: str | None = Field(default=None, description="当前确认的提示词")
    provider: str | None = Field(default=None, description="选择的生图工具（doubao/jimeng）")
```

#### 2.2 对话管理System Prompt

**文件：** `backend/huesaeagents/huesae/agents/subagents/image/prompts.py`（新增）

```
你是生图助手，帮助用户生成图片。你的工作流程：

1. 了解需求：如果用户没有提供具体图片描述，追问"请告诉我您想要生成什么样的图片？"
2. 主动推荐：如果用户说"帮我推荐""推荐一些"，生成1-3个推荐提示词供用户选择
3. 智能扩写：如果用户描述太短（少于10个字），提示补充细节，或询问是否需要扩写
4. 确认闭环：推荐或扩写后，必须询问用户是否满意（"是否可以？""需要修改吗？"）
5. 执行生图：用户明确确认后，选择工具（豆包/即梦）并生成图片
6. 换图支持：图片展示后，询问是否满意，不满意则重新生成

当前可用工具：豆包（写实）、即梦（二次元）、扩写提示词

请以JSON格式输出决策...
```

```python
            # 返回 SHOW_IMAGE 状态
        elif decision.action == "expand":
            # 调用expand_prompt
            # 返回 ASK_CONFIRM 状态
        elif decision.action == "recommend":
            # LLM生成推荐提示词
            # 返回 ASK_CONFIRM 状态
        else:
            # 纯对话：追问、确认、结束
            # 返回对应状态
        
        return {
            "image_step": decision.action,
            "image_prompt": decision.prompt,
            "selected_provider": decision.provider,
            "messages": [AIMessage(content=decision.response)],
        }
```
